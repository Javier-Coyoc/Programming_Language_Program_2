Steps to install V-Lang and run code (for Windows):
1. Go to the official V Programming Language Website and download Windows build: https://vlang.io/
2. Extract the Zip File
3. Enter the recently extracted folder called V and open the terminal inside and type the command: `.\v.exe symlink`. Then type `v version` to confirm that it is installed.
4. In VS code install the V Extension
5. Go in extension settings in VS code and put the V.exe path as the executable path. Optionally you can disable Vls: Enable.

To run the program files in terminal:
1. Make sure your're in the folder directory that has the code files
2. Run this command: `v run .`
3. Then you can enter your input
